# 도메인 모델

애그리거트마다 아래 형식으로 속성·행위·규칙을 정리한다.

## 공통
- 모든 엔티티는 `AbstractEntity` 를 상속해 `id`, `createdAt`, `updatedAt`, `deleted`(soft delete) 를 가진다
- 애그리거트 루트에는 `@AggregateRoot` 를 붙인다
- 정적 팩터리는 `companion object` 에, 내부 엔티티의 생성자·변경 메서드는 `internal` 로 둔다
